# Host Settings Onboarding Copy Map

Date: 2026-05-09
Status: First onboarding and enablement copy packet

## Purpose

Onboarding should teach the new model in the same language the product uses.

## Core story

Teach hosts three jobs:

1. `Set up tonight`
2. `Run the room live`
3. `Save what worked`

Teach save scopes only after the host has already seen a setup work.

## Canonical copy pillars

### Pillar 1: setup by intent

Preferred:

- `Set up tonight`
- `Pick the crowd experience`
- `Pick your operating style`

Avoid:

- `Configure overlays`
- `Adjust queue primitives`
- `Choose persistence scope`

### Pillar 2: live by job

Preferred:

- `Run the room live`
- `Crowd`
- `Flow`
- `Recover`

Avoid:

- implementation-domain labels that require product training first

### Pillar 3: save after success

Preferred:

- `Keep for tonight`
- `Save as my default`
- `Save to workspace template`

Avoid:

- save prompts before the host has tried the setup

## Key copy objects

### Host setup intro

`Set up tonight with one crowd decision, one operating decision, then fine-tune only if this room needs exceptions.`

### Crowd mode helper

`Crowd modes bundle TV chat, scoring, marquee, and trivia so you can shape the room quickly.`

### Operating style helper

`Operating styles bundle queue guardrails, ready-check pacing, and auto stage playback so you can choose how hands-on tonight feels.`

### Save scope helper

`Try it for tonight first. If it works, save it for yourself or your workspace.`

## Channel map

| Channel | Message priority |
| --- | --- |
| in-product setup surface | host jobs and outcomes |
| onboarding docs | Tonight / Live / Save mental model |
| workspace sales/demo copy | reusable templates, branding kits, sponsor leverage |
| support macros | quick scope clarification and recovery language |

## Chief Marketing alignment

When speaking about premium/shared value, lead with:

- reusable workspace templates
- faster branded setup
- repeatable sponsor-ready room prep

Do not lead with:

- storage scopes
- entitlement implementation

## Final rule

If onboarding copy teaches internal architecture before host intent, it is wrong for this migration.
