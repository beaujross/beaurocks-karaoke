# Host Settings Glossary

Date: 2026-05-09
Status: Approved working glossary for the migration

## Host-facing terms

`Tonight`

- the setup surface for this room and this session

`Live`

- the runtime control surface while the show is in progress

`Library / Workspace`

- the shared asset and reusable-template area

`My default`

- a personal saved setup the host can reuse

`Workspace template`

- a reusable shared setup for the workspace

`Restore saved room value`

- revert the draft back to what this room already had saved

`Crowd mode`

- a bundle that changes TV chat, scoring, marquee, and trivia together

`Operating style`

- a bundle that changes queue rules, ready-check pacing, and auto stage playback together

## Internal-only terms

These are acceptable in engineering and support escalation, but should not lead host-facing copy:

- `organization`
- `host defaults`
- `runtime override`
- `workspace settings defaults`
- `persistence locator`
- `provenance`

## Final rule

Use host-facing terms by default. Escalate to internal terms only when debugging requires precision.
